# Cryptocurrency 101

A security-first beginner course about Bitcoin, blockchains, wallets, exchanges, tokens, DeFi, research, law, and practical risk management.

:::warning Educational use only
This course is not financial, investment, legal, accounting, or tax advice. Crypto assets can lose all value. Rules and product details change; verify current primary sources and consult qualified professionals for personal decisions.
:::

## How to use it

Work in order through Module 7, then continue sequentially or revisit topics as needed. Do exercises without committing funds. If you later make a transfer, use a small test and independently verify the network and destination.
