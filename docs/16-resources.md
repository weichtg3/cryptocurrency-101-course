# Resources and update checklist

- [Bitcoin white paper](https://bitcoin.org/bitcoin.pdf)
- [Bitcoin Developer Guide](https://developer.bitcoin.org/devguide/)
- [Ethereum documentation](https://ethereum.org/developers/docs/)
- [CISA phishing guidance](https://www.cisa.gov/secure-our-world/recognize-and-report-phishing)
- [FTC cryptocurrency scam guidance](https://consumer.ftc.gov/articles/what-know-about-cryptocurrency-and-scams)
- [SEC Investor.gov crypto assets](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/crypto-asset-securities)

- [IRS digital assets](https://www.irs.gov/filing/digital-assets)
- [FinCEN virtual currency guidance](https://www.fincen.gov/resources/statutes-regulations/guidance)

## Quarterly maintenance

- [ ] Test every video and external link.
- [ ] Recheck tax and regulatory language against current official sources.
- [ ] Review wallet and exchange screenshots/instructions for drift.
- [ ] Add important security incidents as case studies, without exposing exploit steps.
- [ ] Record changes in CHANGELOG.md.
